# IMS_NEWVERSION — Classic Swing, improved navigation

This edition retains the original university Java Swing appearance. The first navigation row chooses a module; the second row shows that module’s original action buttons. Clicking an action displays its original form or table **inside the main window**. Other versions of the assignment are unaffected.

## Run in VS Code (PowerShell)

```powershell
cd D:\inventory-management-system\IMS_NEWVERSION
javac -d out src/*.java
java -cp out Main
```

Run with your terminal located inside `IMS_NEWVERSION` so the relative `PO/` and `DO/` locations work.

The `PO` and `DO` folders contain eight sample records restored from the original assignment, with delivery contact details anonymized for public sharing. These are **demonstration data**, not real customer contact details.

Test Stock/Add Item, Stock/Search Item, PO and DO list View buttons, and report actions before publishing your screenshots.
